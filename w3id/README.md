# FAIRGraph

Persistent URIs for [FAIRGraph](https://github.com/fairgraph/fairgraph-ontologies): its core
ontology, its standards and the shared vocabularies used by FAIRGraph databases.

## URIs

| URI | Redirects to |
| --- | --- |
| `https://w3id.org/fairgraph/` | The repository on GitHub |
| `https://w3id.org/fairgraph/catalog.json` | The catalog of ontologies, standards and vocabularies |
| `https://w3id.org/fairgraph/ontology` | The core ontology (Turtle; the GitHub page for browsers) |
| `https://w3id.org/fairgraph/vocab/<vocabulary>/<term>` | The vocabulary that defines the term (Turtle; the GitHub page for browsers) |

The files are served by GitHub Pages from <https://github.com/fairgraph/fairgraph-ontologies>.
